What is a Closure?

A closure is a function that has access to variables from its outer (enclosing) scope, even after the outer function has finished executing. In simpler terms, a closure "remembers" the environment in which it was created.

Key Characteristics:

  • ✅ Created when a function is defined inside another function
  • ✅ Inner function accesses its own variables
  • ✅ Inner function accesses outer function's variables
  • ✅ Inner function accesses global variables
  • ✅ Retains access after outer function returns

Why Closures are Useful:

  • 📦 Data encapsulation and privacy
  • 🏭 Function factories
  • ⏱️ Maintaining state in async operations
  • 🧩 Creating modules and revealing patterns
  • 🔄 Implementing currying and partial application
Basic Syntax Example: function outer() { let count = 0; function inner() { count++; return count; } return inner; } const counter = outer(); counter(); // 1 counter(); // 2
Problem 1

2667. Create Hello World Function

📚 Concepts Covered

  • Higher-order functions (functions that return functions)
  • Rest parameters (...args) - collects arguments into an array
  • Closure pattern for function factories

💻 Solution

var createHelloWorld = function() { return function(...args) { return "Hello World"; } };

▶️ Usage Examples

const f = createHelloWorld();

f(); // "Hello World"

f({}, null, 42); // "Hello World" (arguments ignored)

🔍 Explanation

• createHelloWorld() is the outer function that runs once

• It returns an inner function that uses ...args (rest parameter)

• The inner function always returns "Hello World" regardless of arguments

• This demonstrates a function factory pattern

Problem 2

2620. Counter

📚 Concepts Covered

  • Closure with state persistence
  • Maintaining mutable state between function calls
  • Outer function runs once, inner function runs on every call

💻 Solution

var createCounter = function(n) { return function() { n = n + 1; return n - 1; }; };

▶️ Usage Examples

const counter = createCounter(10);

counter(); // 10 (n becomes 11)

counter(); // 11 (n becomes 12)

counter(); // 12 (n becomes 13)

🔍 Explanation

• createCounter(10) stores n = 10 inside the closure

• Each call to counter() increments n and returns the previous value

• The variable n persists between calls because of the closure

• Outer function = setup (runs once)

• Inner function = execution (runs every call)

Problem 3

2704. To Be Or Not To Be

📚 Concepts Covered

  • Returning objects with methods from closures
  • Methods accessing outer scope via closure
  • Strict equality (===) vs loose equality (==)

💻 Solution

var expect = function(val) { return { toBe: function(insideVal) { if (val === insideVal) return true; throw new Error("Not Equal"); }, notToBe: function(insideVal) { if (val !== insideVal) return true; throw new Error("Equal"); } }; };

▶️ Usage Examples

expect(5).toBe(5); // true

expect(5).notToBe(5); // throws "Equal"

expect(5).toBe("5"); // throws "Not Equal" (strict comparison)

🔍 Explanation

• expect(val) creates an object with two methods

• Both toBe() and notToBe() use closure to access val

• Uses strict equality (===, !==) for type-safe comparisons

• This pattern is commonly used in testing frameworks like Jest

Problem 4

2665. Counter II

📚 Concepts Covered

  • Multiple methods sharing state via closure
  • Using 'let' for mutable state
  • Object methods with increment, decrement, and reset

💻 Solution

var createCounter = function(init) { let cur = init; return { increment: function() { cur = cur + 1; return cur; }, decrement: function() { cur = cur - 1; return cur; }, reset: function() { cur = init; return cur; } }; };

▶️ Usage Examples

const counter = createCounter(5);

counter.increment(); // 6

counter.increment(); // 7

counter.decrement(); // 6

counter.reset(); // 5

counter.decrement(); // 4

🔍 Explanation

• createCounter(init) stores values in closure

• All three methods share access to the same cur variable

• increment() and decrement() modify the state

• reset() restores the original value from init

💡 Key Points: var vs let vs const

  • var → old, unsafe, function scoped (avoid ❌)
  • let → modern, block scoped, mutable (use for changing values ✔️)
  • const → modern, block scoped, immutable reference (use for fixed references ✔️)
